第一部分：IPv6 是什么，为什么要用它

简单说，IPv6 是新一代网络地址。你家宽带、手机流量现在基本都有 IPv6，只是很多人不知道。

服务器用的是 IPv6 直连：玩家和服务器之间端到端直连，不经过任何第三方中转服务器。相比联机加速器/内网穿透（隧道），延迟更低、不限中继带宽。

要进服，唯一条件：你的网络支持 IPv6。下面教你确认和开启。

第二部分：确认你有没有 IPv6

方法 1：网页一键检测（最简单）

浏览器打开以下任一网站，看是否显示"支持 IPv6 / 绿色通过"：

  • https://test-ipv6.com
  • https://ipv6test.com

方法 2：Windows 命令行检测

按 Win + R → 输入 cmd → 回车，执行：

ping -6 mcstl.duckdns.org
  • 能收到 来自 ... 的回复 → IPv6 正常，直接去 第四部分进服。
  • 显示 请求超时 → 往下看开启方法。

方法 3：看本机有没有 IPv6 地址

Windows 命令行执行 ipconfig，找 IPv6 地址 那一行。

  • 看到类似 2408:xxxx:... / 240e:... / 2409:... 开头的一长串（带冒号）→ 有 IPv6。
  • 只看到 fe80: 开头 → 那只是本地地址，不算公网 IPv6。
  • 完全没有 IPv6 地址 → 需要开启，看第三部分。

方法 4：手机检测

浏览器打开 https://test-ipv6.com，用当前网络（WiFi 或流量）测试。

第三部分：让设备拿到 IPv6

按你的网络环境选一种。推荐先试 A（手机热点），最省事、成功率最高。

A. 手机热点（推荐，不用动任何设置）

手机流量（4G/5G）国内三大运营商基本都自带 IPv6，开热点让电脑连上即可。

iPhone：

  1. 设置 → 蜂窝网络 → 关闭「WiFi」（确保走的是流量不是 WiFi）。
  2. 设置 → 个人热点 → 打开「允许其他人加入」。
  3. 电脑 WiFi 连上这个热点。
  4. 回到 第二部分 重新检测，通了就能进服。

安卓（华为/小米/OPPO/vivo 等）：

  1. 下拉状态栏关掉 WiFi，确保用流量。
  2. 设置 → 网络和互联网（或「连接与共享」）→ 个人热点 / 便携热点 → 开启。
  3. 电脑 WiFi 连上这个热点。
  4. 重新检测 IPv6，通了就能进服。
注意：电脑此时别同时插着网线，否则可能走网线的 IPv4 通道。断开网线或禁用有线网卡。

B. 家里宽带路由器开 IPv6

国内宽带（电信/联通/移动）几乎都支持 IPv6，很多时候只是路由器默认没开。

  1. 浏览器打开路由器后台。常见地址：192.168.1.1、192.168.0.1、192.168.3.1（路由器背面贴纸也有写）。
  2. 登录（账号密码通常也在贴纸上，或初始 admin/admin）。
  3. 找 IPv6 相关设置，一般在「网络设置 / 上网设置 / IPv6 / 双栈模式」里，把它设为：
  • 开启 / 启用
  • 或「上网方式」选 自动获取 / DHCPv6 / 双栈
  1. 保存重启路由器。
  2. 电脑重新连 WiFi（或重插网线），再检测 IPv6。
有些情况是光猫没开 IPv6：如果你用光猫自带路由功能上网，也要进光猫后台（通常 192.168.1.1）把 IPv6 打开。如果你没有光猫管理员密码，直接用方案 A 手机热点更省事。

C. Windows 电脑开启 IPv6（一般不用做）

正常情况下 Windows 的 IPv6 是默认开启的。只有被手动关掉时才需要重开：

  1. Win + R → 输入 ncpa.cpl → 回车，打开网络连接。
  2. 右键你正在用的网络（WiFi 或以太网）→ 属性。
  3. 勾选「Internet 协议版本 6 (TCP/IPv6)」→ 确定。
  4. 断开重连网络，再检测。

D. Mac 电脑

Mac 一般自动获取 IPv6，无需设置。检测方式：打开 https://test-ipv6.com。若不通，用方案 A 手机热点。

E. 实在没有 IPv6 的兜底方案

如果以上都不行（比如公司/校园网封了 IPv6），可以：

  • 换网络：手机热点、家里宽带、咖啡厅 WiFi 挨个试。
  • 临时用手机玩（基岩版，用流量，见下）。
  • 或者联系房主走备用隧道地址（延迟会高一些，但能进）。

第四部分：进服

Java 版（电脑，官方启动器 / HMCL / PCL 等）

  1. 打开 Minecraft → 「多人游戏」→「添加服务器」。
  2. 服务器地址填：
mcstl.duckdns.org

端口留 25565（默认就是，不用填）。

  1. 加入。

基岩版（手机 / Windows 商店版 / 主机）

  1. 「游戏」→「服务器」→「添加服务器」。
  2. 填：
  • 服务器名称：随便写，比如 mcstl
  • 服务器地址：mcstl.duckdns.org
  • 端口：19132
  1. 保存并加入。
服务器是离线模式，不需要正版账号，随便输入昵称即可进。
IPv6 地址不用加中括号 [ ]。

第五部分：连不上怎么办（按顺序排查）

  1. 重测 IPv6：浏览器开 https://test-ipv6.com，或命令行 ping -6 mcstl.duckdns.org。不通就是网络没 IPv6，回第三部分。
  2. 确认地址没写错：是 mcstl.duckdns.org（全是小写，别漏 .org）。
  3. 换手机热点：这是最稳的验证方式。热点能进、家里 WiFi 不能进 → 是你家网络的问题，按第三部分 B 开 IPv6。
  4. 试备用字面地址：把地址换成 2408:8214:4b2a:5711:d410:13ba:4670:71ed 试试（域名万一解析异常时用）。
  5. 多等几秒：第一次连接如果卡一下，等 5–10 秒，别急着退出重连。

常见问题

Q：一定要开会员/买加速器吗？

不用。IPv6 直连完全免费，不需要任何加速器或会员。

Q：手机能用流量直接进吗？

能。国内手机流量基本都有 IPv6，基岩版直接按第四部分填地址端口即可。

Q：为什么有时第一次进会卡一下？

链路要建立，等几秒就好。之后会快。

Q：这串地址以后会变吗？会变的话怎么办？

会变，但你不用管。域名 mcstl.duckdns.org 由服务器自动更新（每 5 分钟），IP 变了域名自动跟着变，你填的域名永远有效。只有域名万一解析异常时，才用上面的备用字面地址（那个才会变，变了找房主要最新的）。
